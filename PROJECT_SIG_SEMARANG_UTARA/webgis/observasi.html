Input observasi lapangan.

Masukkan hasil pengukuran manual ke basis data monitoring. Data disimpan di backend/monitoring.db dan muncul pada dashboard setelah polling berikutnya.

Lihat dashboard Lihat ambang
Form observasi

Catat satu pembacaan

Semua field bertanda * wajib diisi. Gunakan satuan sesuai parameter: m untuk pasang laut, cm untuk TMA sungai, dan mm/jam untuk hujan.

Jangan simpan kunci API di perangkat publik. Untuk demo lokal, biarkan kosong jika backend tidak memakai kunci.

Sebelum mengirim

  • Gunakan datum dan satuan yang konsisten.
  • Muka air laut dalam meter, TMA sungai dalam sentimeter, hujan dalam mm/jam.
  • Observasi lapangan meningkatkan kualitas data menjadi Tinggi; model eksternal berlabel Sedang; simulasi Rendah.
  • Data ini bukan peringatan resmi. Untuk keadaan darurat, hubungi BPBD/BMKG.

Alternatif CLI

Jika backend berjalan di port 8000:

curl -X POST http://localhost:8000/api/monitoring/observations \
  -H "Content-Type: application/json" \
  -H "X-API-Key: kunci-jika-ada" \
  -d '{"station_id":"Tide Gauge Tambak Lorok","parameter":"tide_level","value":1.82,"unit":"m","source":"field"}'
